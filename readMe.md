Firmware used
Adafruit_SSD1306 and Adafruit_GFX-Library are used on the oled screen to draw and edit the screen the adafruit_GFX makes the photo/display text/figure while SSD1306 is used to communicate with the oled screen.
Bounce2 is used to register the press in the rotary switch 
Encoder is used to register the movment of the rotary switch "movment left and right"
Keypad is used to configure thhe keypad and to be able to register the button press
